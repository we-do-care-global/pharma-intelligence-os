# Pharma Intelligence OS

A modern, open-source dashboard for pharmaceutical data intelligence and analytics built with Vite, React, TypeScript, and TailwindCSS.

## Features

- 📊 Interactive data visualizations
- 💊 Pharmaceutical intelligence modules
- ⚡ Fast development with Vite
- 🔥 Hot module replacement
- 📱 Responsive design with TailwindCSS
- 🧩 Modular and extensible architecture

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
git clone https://github.com/we-do-care-global/pharma-intelligence-os.git
cd pharma-intelligence-os
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Building for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

### Linting

```bash
npm run lint
```

### Testing

```bash
npm run test
```
